# football-players-database
Relational database design and SQL analytics for a football league.
## Overview

This project designs and implements a relational database for football teams, players, stadiums and sponsors.

The database was created using Oracle SQL and includes data integrity constraints and analytical queries.

## Database

The database includes the following entities:

- Teams
- Players
- Stadiums
- Sponsors
- Sponsorships

## Methods

- Relational database design
- Primary and foreign keys
- Unique and CHECK constraints
- Sequences
- Data insertion
- SQL joins
- Aggregations
- Subqueries
- Filtering and sorting

## SQL Analysis

The project includes queries for:

- Team and player analysis
- Player statistics
- Contract values
- Stadium information
- Sponsor revenue
- Team performance
- Grouping and aggregation
- Maximum/minimum values

## Technologies

- Oracle SQL
- SQL Developer

## Repository Structure

- `create_tables.sql` – Database tables and sequences
- `alter_tables.sql` – Keys and constraints
- `insert_data.sql` – Sample data
- `queries.sql` – SQL analysis queries
- `drop_tables.sql` – Database cleanup
